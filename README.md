# Davigo LAN mod

**Русский** | [English](README.en.md)

Неофициальный BepInEx-мод для **DAVIGO: VR vs. PC**, заменяющий облачную игровую сессию на прямое соединение по UDP.

- платная DAVIGO на VR-ПК работает как хост и Giant;
- до четырёх DAVIGO Knight Pass подключаются как Warriors;
- игра по обычной локальной сети с автоматическим обнаружением хоста;
- игра через Porthole с пробросом одного UDP-порта;
- голосовой чат намеренно не переносится.

> [!NOTE]
> Установщики не проверяют точную версию DAVIGO. После обновления игры совместимость может нарушиться, если изменятся внутренние структуры или нативный код.

## Скачать и установить

Откройте [приватный релиз v1.1.0](https://github.com/TimurShigg/DavigoLANmod/releases/tag/v1.1.0) и скачайте нужные архивы:

- `Davigo-LAN-mod-VR-HostPack-v1.1.0.zip` — для владельца платной DAVIGO и VR-шлема;
- `Davigo-LAN-mod-KnightPack-v1.1.0.zip` — для каждого игрока Knight Pass.

Закройте игру, полностью распакуйте архив и запустите `1-Install-VR-Host.bat` либо `1-Install-KnightPass.bat`. Если Windows спросит о сетевом доступе для `Davigo.exe`, разрешите его в частных сетях. Первый запуск после установки может занять около минуты.

Подробности: [установка и игра по LAN](docs/INSTALL-RU.md), [Porthole](docs/PORTHOLE-RU.md), [устранение неполадок](docs/TROUBLESHOOTING-RU.md).

## Возврат к обычной сетевой игре

Чтобы снова играть через стандартные онлайн-серверы DAVIGO, полностью закройте игру и удалите мод:

- на VR-хосте запустите `2-Uninstall-VR-Host.bat` из Host Pack;
- на компьютере с Knight Pass запустите `Uninstall-KnightPass.bat` из Knight Pack.

`2-Mode-LAN.bat` и `2-Mode-Porthole.bat` только переключают тип прямого соединения и не возвращают обычный сетевой режим DAVIGO.

## Игра через Porthole

### Хост с VR

1. Устанавливает Host Pack и запускает платную DAVIGO.
2. Создаёт сетевую комнату DAVIGO обычным способом.
3. Создаёт лобби Porthole и добавляет в раздачу **UDP 7542** от `Davigo.exe`.
4. Оставляет DAVIGO и Porthole запущенными. Переключать режим на хосте не требуется.

### Игрок Knight Pass

1. Закрывает Knight Pass перед сменой режима.
2. Входит в лобби Porthole хоста и **явно разрешает UDP 7542**. Одного входа в лобби недостаточно.
3. Запускает `2-Mode-Porthole.bat`.
4. Запускает Knight Pass и подключается через обычное сетевое меню с любым четырёхзначным кодом.

Для возврата к физической локальной сети клиент закрывает игру и запускает `2-Mode-LAN.bat`. UDP 7543 и Virtual LAN Porthole для проверенной схемы не требуются.

## Порты

| Протокол | Порт | Назначение |
|---|---:|---|
| UDP | 7542 | игровой трафик Fusion |
| UDP | 7543 | обнаружение хоста только в обычной LAN |

## Сборка исходника

Проект ссылается на библиотеки установленной DAVIGO и созданные BepInEx interop-сборки. Инструкция: [docs/BUILD-RU.md](docs/BUILD-RU.md).

Исходный код доступен прямо в ветке `main`: [`Plugin.cs`](Plugin.cs) и [`DavigoLANmod.csproj`](DavigoLANmod.csproj).

## Ограничения

- Встроенный голос DAVIGO не является частью LAN-мода. Используйте Discord, Steam Voice и т. п.
- Лобби с более чем одним Giant не тестировалось; корректная работа такого режима не гарантируется.
- После обновления DAVIGO нативные патчи, вероятно, потребуется адаптировать.

Проект не связан с разработчиками DAVIGO. Репозиторий не содержит файлов игры.
