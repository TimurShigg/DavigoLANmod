# DAVIGO True LAN

**Русский** | [English](README.en.md)

Неофициальный BepInEx-мод для **DAVIGO: VR vs. PC**, заменяющий облачную игровую сессию на прямое соединение по UDP.

- платная DAVIGO на VR-ПК работает как хост и Giant;
- до четырёх DAVIGO Knight Pass подключаются как Warriors;
- игра по обычной локальной сети с автоматическим обнаружением хоста;
- игра через Porthole с пробросом одного UDP-порта;
- голосовой чат намеренно не переносится.

> [!WARNING]
> Версия 1.0.1 привязана к DAVIGO **0.5.2A-1493 (Windows x64)**. Установщики проверяют сборку игры и остановятся при несовпадении.

## Скачать и установить

Откройте [приватный релиз v1.0.1](https://github.com/TimurShigg/DavigoLANmod/releases/tag/v1.0.1) и скачайте нужные архивы:

- `DAVIGO-True-LAN-VR-HostPack-v1.0.1.zip` — для владельца платной DAVIGO и VR-шлема;
- `DAVIGO-True-LAN-KnightPack-v1.0.1.zip` — для каждого игрока Knight Pass.

Закройте игру, полностью распакуйте архив и запустите `1-Install-VR-Host.bat` либо `1-Install-KnightPass.bat`. Если Windows спросит о сетевом доступе для `Davigo.exe`, разрешите его в частных сетях. Первый запуск после установки может занять около минуты.

Подробности: [установка и игра по LAN](docs/INSTALL-RU.md), [Porthole](docs/PORTHOLE-RU.md), [устранение неполадок](docs/TROUBLESHOOTING-RU.md).

## Порты

| Протокол | Порт | Назначение |
|---|---:|---|
| UDP | 7542 | игровой трафик Fusion |
| UDP | 7543 | обнаружение хоста только в обычной LAN |

## Сборка исходника

Проект ссылается на библиотеки установленной DAVIGO и созданные BepInEx interop-сборки. Инструкция: [docs/BUILD-RU.md](docs/BUILD-RU.md).

## Ограничения

- Steam и фоновые функции игры всё ещё могут обращаться в интернет; напрямую идёт именно игровой Fusion-трафик.
- Встроенный голос DAVIGO не является частью LAN-мода. Используйте Discord, Steam Voice и т. п.
- Лобби с более чем одним Giant не тестировалось; корректная работа такого режима не гарантируется.
- После обновления DAVIGO нативные патчи, вероятно, потребуется адаптировать.
- Grab and Drag Locomotion — штатная экспериментальная настройка DAVIGO и к этому моду не относится.

Проект не связан с разработчиками DAVIGO. Репозиторий не содержит файлов игры.
