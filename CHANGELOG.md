# Changelog

## 1.1.0

- Проект переименован в Davigo LAN mod.
- Удалена проверка точного номера и SHA-256 сборки игры из мода и установщиков.
- LAN-обнаружение больше не передаёт и не сравнивает номер сборки DAVIGO.
- Добавлены расширенные инструкции по переключению режима, хостингу и подключению Knight Pass через Porthole.
- Подтверждено отсутствие собственных патчей локомоции: мод меняет только сетевую часть, роли и запуск матча.

## 1.0.1

- Исправлено назначение ролей: VR-хост получает только Giant, удалён лишний локальный Warrior.
- Подтверждено прямое соединение платного DAVIGO-хоста и Knight Pass через UDP 7542.
- Подтверждена загрузка боевой сцены на обеих сторонах.
- Добавлены отдельные установочные архивы и деинсталляторы для VR-хоста и Knight Pass.
- Добавлены переключатели Knight Pass между обычной LAN и Porthole.
