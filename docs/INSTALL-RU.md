# Установка и игра по локальной сети

## VR-хост

1. Полностью закройте DAVIGO.
2. Распакуйте `DAVIGO-True-LAN-VR-HostPack-v1.0.1.zip`.
3. Запустите `1-Install-VR-Host.bat`.
4. Если Steam-библиотека находится не в стандартной папке, укажите папку платной игры `Davigo`, а не `DavigoKnightPass`.
5. При запросе Брандмауэра Windows разрешите `Davigo.exe` доступ в частных сетях.

Отдельно выбирать режим LAN/Porthole на VR-хосте не требуется: сервер всегда слушает `UDP 7542`.

## Игрок Knight Pass

1. Полностью закройте Knight Pass.
2. Распакуйте `DAVIGO-True-LAN-KnightPack-v1.0.1.zip`.
3. Запустите `1-Install-KnightPass.bat`.
4. Запустите `2-Mode-LAN.bat`.
5. При запросе Брандмауэра Windows разрешите `Davigo.exe` доступ в частных сетях.

## Порядок запуска матча

1. VR-хост запускает обычную платную DAVIGO через Steam и создаёт сетевую комнату.
2. После появления хоста в лобби игроки запускают Knight Pass.
3. Игроки подключаются через обычное сетевое меню. Если нужен код комнаты, можно ввести любые четыре цифры.
4. Хост выбирает карту и запускает матч обычной кнопкой.

Проверена схема с одним VR-хостом/Giant. Лобби с более чем одним Giant не тестировалось и может работать некорректно.

## Удаление

Запустите `2-Uninstall-VR-Host.bat` на VR-хосте либо `Uninstall-KnightPass.bat` на клиенте. Деинсталлятор удаляет плагин и его конфигурацию, но оставляет BepInEx, чтобы не повредить другие установленные моды.
