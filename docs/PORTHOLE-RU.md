# Игра через Porthole

Для проверенной схемы Virtual LAN не требуется. Porthole проксирует игровой `UDP 7542` на клиентский `127.0.0.1:7542`.

Режим переключается только на ПК с Knight Pass и только при закрытой игре:

- `2-Mode-Porthole.bat` — подключение через Porthole;
- `2-Mode-LAN.bat` — возврат к обычной физической LAN.

## Хост

1. Установите VR Host Pack. Отдельного переключателя режима на хосте нет.
2. Запустите платную DAVIGO и создайте сетевую комнату.
3. Создайте лобби Porthole.
4. Добавьте в раздачу **UDP 7542** от процесса `Davigo.exe`.
5. Пригласите друзей и оставьте DAVIGO и Porthole запущенными.

## Каждый клиент

1. Установите Knight Pack и полностью закройте игру перед сменой режима.
2. Войдите в лобби Porthole хоста.
3. **Явно нажмите разрешение/подтверждение для UDP 7542.** Одного входа в лобби недостаточно.
4. Запустите `2-Mode-Porthole.bat`. Скрипт записывает клиенту адрес `127.0.0.1:7542` и отключает LAN-обнаружение.
5. Запустите Knight Pass и подключитесь через обычное сетевое меню с любым четырёхзначным кодом.
6. После появления рыцаря в комнате хост запускает матч обычной кнопкой.

Для возвращения к физической локальной сети закройте игру и запустите `2-Mode-LAN.bat`.

## Что не требуется

- UDP 7543 через Porthole не нужен;
- переключатель режима на VR-хосте не нужен;
- Virtual LAN Porthole для этой схемы не нужен.
