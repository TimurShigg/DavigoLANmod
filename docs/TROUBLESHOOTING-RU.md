# Устранение неполадок

## LAN-хост не находится

1. Убедитесь, что все ПК находятся в одной подсети, а сеть Windows имеет профиль «Частная».
2. Отключите VPN либо исключите из него обе копии `Davigo.exe`.
3. Проверьте, что брандмауэр разрешает игре UDP 7542 и UDP 7543.
4. В конфигурации клиента `BepInEx/config/dev.codex.davigo.lanmod.cfg` можно вручную указать локальный IPv4 хоста:

   ```ini
   HostIPv4 = 192.168.0.213
   ```

5. Перезапустите Knight Pass.

## Porthole подключается с тайм-аутом

Главная проверка: клиент должен не только войти в лобби Porthole, но и вручную разрешить предложенный хостом `UDP 7542`. После этого запустите `2-Mode-Porthole.bat` при закрытой игре.

## Логи

Лог находится в `BepInEx/LogOutput.log` внутри папки соответствующей игры. Полезные строки:

- `Discovered DAVIGO LAN host`;
- `Fusion connected to LAN server`;
- `DAVIGO LAN battle scene is ready`.

Ошибки OpenXR на ПК Knight Pass обычно не относятся к сетевому соединению.
